- 高光定义依赖物体级渲染、白底、局部相对亮度、分位数阈值和 highlight score。
- 数据加载器默认是“同视角换光”的 object-centric relighting，且 `random_lighting_%03d.png` 被当成 condition OOD 分支，见 [dataset_relighting_training.py](/4T/CXY/Neural_Gaffer/dataset/dataset_relighting_training.py)。

# 2026-04-02 投稿实验执行清单（主线与频域辅助）

这份文档的目的不是继续讨论“该怎么写论文”，而是把当前仓库里已经存在的配置、脚本、日志习惯和论文需求拼成一份可以直接照着执行的清单。

### 1.3 一个需要明确的现实情况

当前 `configs/methods/` 里只有 3 个公开配置文件：

1. `highlight_full_main_showcase.txt`
2. `highlight_frequency_auxiliary_spuru.txt`
3. `highlight_hybrid_probe.txt`

这意味着：

1. 论文主线的 `full main` 已经有稳定配置
2. 频域辅助有单独配置
3. 但 clean ablation 的每一行还没有全部拆成单独的 method config 文件

所以现阶段最合理的做法是：

1. 主模型和频域辅助先按现成 config 跑
2. clean ablation 先参考历史 run 和 queue 脚本参数
3. 后面如果要补严格复现实验，再把每一行 clean ablation 升级成独立 config

这条线的作用不是做 clean ablation，而是拿到论文主结果模型。

## 5. 流水线 C：频域辅助补充实验

### 5.1 目的

这条线回答的问题是：

**在不改现有高光定义模块的前提下，额外引入低频/高频分离辅助，是否能进一步改善 `ra/tu` 一类更依赖整体照明和软波瓣高光的情况。**

### 5.2 当前配置特点

当前频域配置文件是：

- [highlight_frequency_auxiliary_spuru.txt](/4T/CXY/Neural_Gaffer/configs/methods/highlight_frequency_auxiliary_spuru.txt)

它的关键点是：

1. `use_frequency_separation_auxiliary_loss = true`
2. `frequency_low_loss_weight = 0.08`
3. `frequency_high_loss_weight = 0.03`
4. `frequency_blur_sigma = 1.5`
5. `highlight_relative_mode = none`

这意味着它更接近：

1. image-space quantile + blur 版本的补充线
2. 不是最终 full main method 的严格增量版

因此在论文里更适合写成：

1. `auxiliary enhancement`
2. 或附录中的 `frequency-aware extension`

### 5.3 推荐命令

```bash
CUDA_VISIBLE_DEVICES=0 \
NCCL_P2P_DISABLE=1 \
NCCL_IB_DISABLE=1 \
/4T/conda_envs/neural_gaffer_5090/bin/torchrun \
  --standalone --nnodes=1 --nproc_per_node=1 \
  neural_gaffer_training.py \
  --method_config configs/methods/highlight_frequency_auxiliary_spuru.txt \
  --data_config configs/datasets/current_local_official.txt
```

### 5.4 参考历史自动队列

当前仓库里已经有对应的旧队列脚本：

- [queue_after_two_best_add_frequency.sh](/4T/CXY/Neural_Gaffer/scripts/queue_after_two_best_add_frequency.sh)

它说明这条线原本是接在 clean ablation 后跑的，不是第一优先级主线。

### 5.5 在论文中的建议位置

最稳妥的写法是：

1. 正文一句话提到：我们还尝试了一个训练期频域辅助模块
2. 附录给表：对 `uu/us/ra/tu` 的增减趋势
3. 不把它写成主方法核心组成部分

## 7. 流水线 E：论文资产导出

这条线的目标是从训练好的 checkpoint 导出：

1. official 对比图
2. official-demo 对比图
3. 高光专项评测表
4. 高光 mask / 诊断图

### 7.1 第一步：生成 manifest

以 `uu` 为例：

```bash
python Neural_Gaffer/scripts/create_relighting_comparison_manifest.py \
  --preset uu \
  --sample-count 6 \
  --output Neural_Gaffer/logs/relighting_comparison/paper_uu_manifest.json
```

`us`、`ra` 同理。

### 7.2 第二步：跑 ours

示例：

```bash
python Neural_Gaffer/scripts/run_ours_on_comparison_manifest.py \
  --manifest Neural_Gaffer/logs/relighting_comparison/paper_uu_manifest.json \
  --model-dir Neural_Gaffer/logs/neural_gaffer_training_main_current_original_official_ecommerce \
  --method-name ours_full \
  --output-root Neural_Gaffer/logs/relighting_comparison/paper_uu_ours_full_preds
```

如果要指定某个 checkpoint：

```bash
python Neural_Gaffer/scripts/run_ours_on_comparison_manifest.py \
  --manifest Neural_Gaffer/logs/relighting_comparison/paper_uu_manifest.json \
  --model-dir Neural_Gaffer/logs/neural_gaffer_training_main_current_original_official_ecommerce \
  --checkpoint-path Neural_Gaffer/logs/neural_gaffer_training_main_current_original_official_ecommerce/checkpoint-80000/model.safetensors \
  --method-name ours_full \
  --output-root Neural_Gaffer/logs/relighting_comparison/paper_uu_ours_full_preds
```

### 7.3 第三步：可选跑 official demo

```bash
python Neural_Gaffer/scripts/run_official_demo_on_comparison_manifest.py \
  --manifest Neural_Gaffer/logs/relighting_comparison/paper_uu_manifest.json \
  --output-root Neural_Gaffer/logs/relighting_comparison/paper_uu_official_demo_preds \
  --method-name official-demo
```

### 7.4 第四步：导出对齐资产

```bash
python Neural_Gaffer/scripts/export_relighting_comparison_assets.py \
  --manifest Neural_Gaffer/logs/relighting_comparison/paper_uu_manifest.json \
  --output-dir Neural_Gaffer/logs/relighting_comparison/paper_uu_assets \
  --method-root ours_full=/4T/CXY/Neural_Gaffer/logs/relighting_comparison/paper_uu_ours_full_preds \
  --method-root official-demo=/4T/CXY/Neural_Gaffer/logs/relighting_comparison/paper_uu_official_demo_preds
```

### 7.5 第五步：生成 panel

基础 panel：

```bash
python Neural_Gaffer/scripts/build_relighting_comparison_panel.py \
  --assets-manifest Neural_Gaffer/logs/relighting_comparison/paper_uu_assets/exported_assets_manifest.json \
  --methods ours_full official-demo \
  --output Neural_Gaffer/logs/relighting_comparison/paper_uu_panel.png
```

带高光 mask 的诊断 panel：

```bash
python Neural_Gaffer/scripts/build_relighting_comparison_panel.py \
  --assets-manifest Neural_Gaffer/logs/relighting_comparison/paper_uu_assets/exported_assets_manifest.json \
  --columns input_image method:official-demo method_mask:official-demo method:ours_full method_mask:ours_full ground_truth gt_highlight_mask target_lighting \
  --output Neural_Gaffer/logs/relighting_comparison/paper_uu_panel_with_masks.png
```

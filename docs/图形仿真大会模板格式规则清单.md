# 图形仿真大会 `.doc` 模板格式规则清单

本文档基于 `图形仿真大会模板.doc` / `图形仿真大会投稿.doc` 的可提取文本与对象线索整理。

当前环境下只能稳定提取到正文占位内容、部分字体名称、公式对象与参考文献类型占位，不能像在 Word 中那样直接读取完整样式表。因此本清单分为“可确认规则”和“待人工核对规则”两部分。

## 1. 源文件

- 模板文件：`/4T/CXY/Neural_Gaffer/docs/图形仿真大会模板.doc`
- 投稿草稿：`/4T/CXY/Neural_Gaffer/docs/图形仿真大会投稿.doc`
- 文件类型：老式 `Microsoft Word .doc`
- 页数：`3`
- 已观察到的字体线索：`Times New Roman`、`SimSun`、`SimHei`、`Arial`、`Symbol`、`Cambria Math`
- 已观察到的公式对象线索：`MathType`、`Equation Native`

## 2. 可确认规则

### 2.1 文章结构

模板中明确包含以下结构：

1. 题目 `Title`
2. 作者 `Name Namename1,3 / Name Namename2`
3. 作者单位与地址
4. 摘要 `Abstract`
5. 关键词 `Keywords`
6. 正文分级标题
7. 表题 `Tab.1  Table title`
8. 图题 `Fig1.  Figure caption`
9. 公式与右侧编号 `(1) (2) (3)`
10. 参考文献
11. 作者信息项，如出生年份、E-mail

### 2.2 标题层级

模板中明确出现了以下标题层级：

- 一级以下示例：`1.1`
- 二级以下示例：`1.1.1`
- 后续还有 `1.1.2`

可判断模板至少支持到三级编号标题。

### 2.3 摘要与关键词

模板中出现了：

- `Abstract ...`
- `Keywords: keywords; keywords; keywords; keywords(`

由此可以确认：

- 摘要单独成段
- 关键词使用 `Keywords:` 引导
- 关键词之间用分号 `;` 分隔

### 2.4 图、表、公式

模板中明确出现了：

- 表题格式：`Tab.1  Table title`
- 图题格式：`Fig1.  Figure caption`
- 公式对象：`Equation.DSMT4`
- 公式编号：右侧独立编号 `(1)`、`(2)`、`(3)`

因此可以确认：

- 图表标题使用英文缩写形式
- 公式采用独立陈列并编号
- 模板原始公式很可能由 MathType 或老式 Word 公式对象生成

### 2.5 参考文献类型

模板中明确出现了以下文献类型占位：

- `[J]`
- `[C]//`
- `[N]`
- `[S]`
- `[P]`
- `[B]`
- `[Z]`
- `[M]`
- `[D]`

这说明模板参考文献写法接近中文论文常见的国标式类型标记。

### 2.6 字体线索

文本中可确认出现：

- `Times New Roman`
- `SimSun`
- `SimHei`

因此基本可以判断：

- 西文正文大概率以 `Times New Roman` 为主
- 中文正文大概率以 `宋体（SimSun）` 为主
- 黑体（SimHei）可能用于标题或强调项

## 3. 高概率推断规则

以下内容不是从样式表直接读出的，而是依据模板占位文本做出的高概率推断：

### 3.1 语言与排版习惯

- 模板正文示例偏英文格式
- 但字体集合包含中文论文常用 `SimSun` / `SimHei`
- 因此模板很可能服务于中英文混排，或允许中文稿件按英文图表标题和英文摘要组织

### 3.2 字号与段落线索

模板中多次出现：

- `Times New Roamn`
- `0.5~0.75`

这里大概率是在说明：

- 某些段落或标题使用 `Times New Roman`
- 行距或段距范围可能在 `0.5~0.75` 行或相近量级

但由于原始样式无法完整读取，这里不能把 `0.5~0.75` 直接当成最终定值。

### 3.3 参考文献风格

结合类型标记来看，参考文献更像：

- 顺序编码制
- 中文标注习惯
- 文献类型码附在题名后

## 4. 当前无法确认、必须人工核对的规则

这些内容仅靠当前 `.doc` 二进制文本提取无法可靠确定：

- 页面尺寸
- 上下左右页边距
- 栏数，是否双栏
- 题目、作者、单位的精确字号
- 正文字号
- 行距的精确值
- 段前段后距离
- 首行缩进长度
- 页眉页脚具体样式
- 参考文献条目缩进方式
- 图题表题是居中还是左对齐
- 图题在图下还是图上，表题在表上还是表下
- 公式编号与正文的垂直对齐细节

## 5. 对 LaTeX 复现的可行性判断

### 5.1 可稳定复现

- 题目、作者、单位块
- 摘要、关键词结构
- 多级标题编号
- 图题、表题、公式编号
- 参考文献条目框架
- 中英文混排的基本字体风格

### 5.2 难以保证和 Word 完全一致

- 精确分页
- 图表浮动位置
- MathType 公式对象回转到 Word 的效果
- Word 样式绑定关系
- 中英文字体的细微度量差异

## 6. 建议的工作方式

如果目标是“先写论文，再尽量靠近模板”：

- 先用 LaTeX 保证结构、编号、图表、公式和参考文献规范
- 最后再对照 Word 模板人工校一轮页边距、字号、段距和分页

如果目标是“最终严格提交 `.doc/.docx`”：

- 以 Word 为最终交付母版
- 将 LaTeX 作为写作和版本管理工具，而不是作为最终无损源格式

## 7. LaTeX 映射建议

建议在 LaTeX 中先采用以下映射：

- 文档类：`ctexart`
- 西文字体：Times 风格
- 中文正文字体：宋体风格
- 中文标题字体：黑体风格
- 图题：`Fig. 1`
- 表题：`Tab. 1`
- 公式编号：右侧圆括号编号
- 参考文献：先用手工 `thebibliography`，后续再细调为会议要求

## 8. 后续人工核对清单

等你在有 Word 的环境里打开模板后，最值得补核的项目只有这几项：

1. 页边距和单双栏
2. 题目、作者、单位、正文、摘要、关键词的字号
3. 行距、首行缩进、段前段后
4. 图题表题的相对位置与对齐方式
5. 参考文献缩进和字号

这五项一旦补齐，LaTeX 模板就能再精修到更接近最终投稿版。

# 2026-03-27 W\&B 图示候选清单（中文版）

本文档记录当前从本地 `wandb/media` 中筛出的第一版候选图片，目标是为中文初稿中的问题定义图、主对比图、效率图和诊断图提供可直接替换的素材路径。

## 1. 使用原则

当前 `wandb/media` 中的大多数图片本身已经是“多列拼图”：

- 左侧通常包含 `input / gt / pred_0 / pred_1`
- 中间包含 `highlight_mask / highlight_weight`
- 右侧包含 `env_ldr / env_hdr`

因此在论文中不建议直接原图整张塞入，而更适合：

1. 先从这些大图中裁出左侧结果区作为主对比图
2. 再从中间裁出 `highlight_mask / highlight_weight` 用作诊断图
3. 若需要解释光照条件，再从右侧裁 `env_ldr / env_hdr`

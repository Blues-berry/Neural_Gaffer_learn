# 频域分离辅助模块原理与技术细节

## 1. 模块定位

这个模块是一个**额外的训练辅助分支**，目标是在**不改现有高光监督定义模块**的前提下，补足主模型在以下两类视觉成分上的约束平衡：

- 低频部分：整体照明、面光源软影、缓变反射分布
- 高频部分：尖锐高光、局部亮斑、细节残差

它不是一个新的 backbone，也不是新的推理模块。  
它只在训练阶段参与 loss 计算，推理时不增加网络结构和推理耗时。

对应实现文件：

- [frequency_separation_auxiliary.py](/4T/CXY/Neural_Gaffer/frequency_separation_auxiliary.py)
- [neural_gaffer_training.py](/4T/CXY/Neural_Gaffer/neural_gaffer_training.py)
- [parse_args.py](/4T/CXY/Neural_Gaffer/parse_args.py)

## 2. 核心思想

当前主线方法已经有一套完整的高光监督链路：

- 前景 mask
- highlight quantile threshold
- blur 仅用于 threshold estimation
- image-space highlight weighted loss

这套方法对 `uu/us` 很有效，但容易和 `ra/tu` 出现 trade-off。  
频域分离辅助模块的想法是：

1. 用一个轻量级的高斯模糊，把图像分成低频和高频两部分。
2. 对低频部分，用普通重建约束兜住整体照明与软阴影。
3. 对高频部分，用现有 highlight weight map 做加权残差约束，继续强调高光。

所以它不是“替换”现有高光模块，而是“给现有高光模块配一个低频照明锚点”。

## 3. 为什么不用 FFT，而用 Gaussian + Residual

这里没有上完整 FFT 或复杂拉普拉斯金字塔，原因是：

- 现有工程里已经稳定使用了高斯模糊逻辑，接入成本低。
- 目标不是研究严格频谱分析，而是构造一个**可控、轻量、易消融**的低频/高频监督。
- Gaussian blur 后的残差已经足够把“软照明”与“尖锐高光”大致拆开。
- 不引入新的复杂频域算子，更适合论文里做 clean ablation。

因此，当前实现本质上是一个**单尺度频域近似分离模块**，更准确地说接近：

`Gaussian low-pass + residual high-pass`

## 4. 数学定义

设：

- 预测图像为 `I_pred`
- 真实图像为 `I_gt`
- 高斯模糊算子为 `G_sigma(.)`

则：

### 4.1 低频分量

`I_pred_low = G_sigma(I_pred)`

`I_gt_low = G_sigma(I_gt)`

低频主要对应：

- 大尺度照明
- 面光源软阴影
- 缓慢变化的漫反射与亮度分布

### 4.2 高频分量

`I_pred_high = I_pred - I_pred_low`

`I_gt_high = I_gt - I_gt_low`

高频主要对应：

- 尖锐高光
- 边缘细节
- 局部亮斑和快速变化残差

### 4.3 损失形式

低频损失：

`L_low = Mean_fg( loss(I_pred_low, I_gt_low) )`

高频损失：

`L_high = Mean_hw( loss(I_pred_high, I_gt_high) )`

其中：

- `Mean_fg` 表示在前景 mask 上做加权平均
- `Mean_hw` 表示在现有 highlight weight map 上做加权平均
- `loss` 当前支持 `L1` 或 `L2`

最终频域辅助损失：

`L_freq = lambda_low * L_low + lambda_high * L_high`

总训练损失为：

`L_total = L_diffusion + lambda_img * L_imgspace + lambda_probe * L_probe + L_freq`

注意这里 `L_freq` 内部已经乘上了 `lambda_low` 和 `lambda_high`，在训练主循环里直接相加。

## 5. 关键设计原则

### 5.1 不修改现有高光定义

高光定义仍然完全来自已有流水线，而不是重新在高频残差图上定义一套新高光：

- highlight score
- highlight mask
- highlight weight map

这些仍然基于原始 GT 图像计算。

这样做的好处是：

- 不破坏当前已经稳定的高光语义
- 不会把“高频残差”这种 signed map 直接塞进 quantile/relative 逻辑
- 消融更干净，论文叙事更清晰

### 5.2 低频和高频分别服务不同目标

低频分支负责：

- 稳住整体 relighting
- 保住面光源和软阴影
- 尽量补 `ra/tu`

高频分支负责：

- 保住高光局部细节
- 配合现有 highlight-weighted supervision
- 尽量守住 `uu/us`

### 5.3 只在训练阶段启用

模块只依赖：

- 已解码的 `pred_x0_image`
- GT image
- foreground mask
- highlight weight map

它不会改变推理图结构，因此：

- 不增加推理参数量
- 不增加推理时延
- 不改变推理流程

## 6. 代码工作流程

## 6.1 模块输入

在训练阶段，模块输入是：

- `pred_x0_image`
- `gt_image`
- `foreground_mask`
- `highlight_weight_map`
- `blur_sigma`
- `blur_kernel_size`
- `low_loss_weight`
- `high_loss_weight`
- `low_loss_type`
- `high_loss_type`

来自训练主循环的接入点在：

- [neural_gaffer_training.py](/4T/CXY/Neural_Gaffer/neural_gaffer_training.py)

## 6.2 前景与高光权重来源

训练里先通过原有流水线得到：

- `image_foreground_mask`
- `image_weight_map`

对应逻辑来自：

- `compute_training_highlight_maps`
- `compute_training_highlight_weight_map`

也就是说，频域模块**直接复用已有的前景和高光结果**。

## 6.3 高斯核大小解析

如果没有显式给 kernel size，模块会根据 `sigma` 自动推导：

- 半径近似取 `round(3 * sigma)`
- kernel size = `2 * radius + 1`
- 自动保证为奇数

这部分在 `_resolve_blur_kernel_size` 中实现。

## 6.4 低频分支

当 `kernel_size <= 1` 或 `sigma <= 0` 时，不做模糊，低频分量直接退化为原图。

否则使用：

- `kornia.filters.gaussian_blur2d`

分别对 `pred_image` 和 `gt_image` 做二维高斯模糊。

## 6.5 高频分支

高频分量通过残差获得：

- `pred_high = pred_image - pred_low`
- `gt_high = gt_image - gt_low`

这里的高频是图像残差，不是单独定义的新高光图。

## 6.6 低频损失

低频每像素损失：

- `L1`: `abs(pred_low - gt_low)`
- `L2`: `(pred_low - gt_low)^2`

然后在前景 mask 上做加权平均。

这样白背景不会主导低频重建目标。

## 6.7 高频损失

高频每像素损失：

- `L1`: `abs(pred_high - gt_high)`
- `L2`: `(pred_high - gt_high)^2`

然后用现有 `highlight_weight_map` 做加权平均。

注意：

- 这里不是只看二值高光 mask
- 而是复用现有的 soft highlight weighting

因此高频分支仍然保留了“更关注高光区域”的训练意图。

## 6.8 输出内容

模块返回一个 dataclass：

- `total_loss`
- `low_frequency_loss`
- `high_frequency_loss`
- `pred_low_abs_mean`
- `gt_low_abs_mean`
- `pred_high_abs_mean`
- `gt_high_abs_mean`

后四项主要用于日志监控与调试。

## 7. 与主训练流程的关系

模块并不是独立运行，而是插在当前 image-space 辅助分支旁边：

1. 扩散模型输出 `model_pred`
2. 恢复 `pred_x0_latents`
3. VAE decode 得到 `pred_x0_image`
4. 原有 image-space highlight loss 照常算
5. 频域辅助模块再对 `pred_x0_image` 和 `gt_image` 做 low/high 分解并计算附加 loss
6. 最终一起进入总 loss

所以它和已有 image-space loss 的关系是：

- 不是二选一
- 不是替代关系
- 而是并行叠加的辅助监督

## 8. 当前配置参数含义

在当前实验配置 [highlight_frequency_auxiliary_spuru.txt](/4T/CXY/Neural_Gaffer/configs/methods/highlight_frequency_auxiliary_spuru.txt) 中，这个模块的关键参数是：

- `use_frequency_separation_auxiliary_loss = true`
- `frequency_low_loss_weight = 0.08`
- `frequency_high_loss_weight = 0.03`
- `frequency_loss_warmup_steps = 5000`
- `frequency_blur_sigma = 1.5`
- `frequency_blur_kernel_size = 0`
- `frequency_low_loss_type = l1`
- `frequency_high_loss_type = l1`

这些参数的直觉是：

- 低频比高频更重：优先补 `ra/tu`
- 高频只做轻量约束：避免和现有高光监督打架
- `sigma=1.5`：做轻量而不是极强的分离
- `warmup=5000`：前期先让主任务收敛，再逐步引入频域辅助

## 9. 为什么高频权重不直接改成新 relative loss

这是一个容易误解的点。

当前模块没有把“现有 relative brightness loss”直接搬到高频残差上，原因是：

- 高频残差是 signed 的
- 其分布不再等价于原始 luminance
- 现有 quantile / threshold / relative 逻辑建立在正常亮度图上

如果强行把高频残差当作新的“亮度图”重新做 quantile/highlight 定义，语义会变差，也更容易不稳。

因此当前实现选择：

- 高频分量用于重建 residual
- 但高光权重仍然来自原图上的现有 highlight pipeline

这是一种更稳的折中。

## 10. 适合画原理图的结构

建议把原理图画成四层。

### 第 1 层：主干输入输出

- Noisy latent
- UNet prediction
- `pred_x0_latents`
- VAE decode
- `pred_x0_image`

### 第 2 层：现有高光监督分支

- GT image
- Foreground mask
- Quantile threshold
- Highlight score / weight map
- Image-space highlight loss

### 第 3 层：新增频域辅助分支

- `pred_x0_image -> Gaussian blur -> pred_low`
- `gt_image -> Gaussian blur -> gt_low`
- `pred_high = pred_x0_image - pred_low`
- `gt_high = gt_image - gt_low`

再分成两条：

- Low-frequency branch:
  - `(pred_low, gt_low)` + foreground mask -> `L_low`
- High-frequency branch:
  - `(pred_high, gt_high)` + existing highlight weight map -> `L_high`

### 第 4 层：总损失融合

- `L_diffusion`
- `lambda_img * L_imgspace`
- `lambda_low * L_low`
- `lambda_high * L_high`
- optional probe loss
- `L_total`

## 11. 适合画图时标注的张量尺寸

以当前常见设置为例：

- 输入/GT 图像：`B x 3 x 256 x 256`
- foreground mask：`B x 1 x 256 x 256`
- highlight weight map：`B x 1 x 256 x 256`
- blurred image：`B x 3 x 256 x 256`
- residual high-frequency：`B x 3 x 256 x 256`

如果图里还要画 latent：

- `pred_x0_latents` 常见是 `B x 4 x 32 x 32`

## 12. 实验与消融建议

如果要专门做这个模块的 ablation，最建议的对照是：

1. baseline mainline  
2. `+ low-frequency only`
3. `+ high-frequency only`
4. `+ low + high` full frequency auxiliary

这样能回答：

- 是否真的是低频分支在补 `ra/tu`
- 高频残差分支是否只是重复现有高光监督
- 两者组合有没有互补

## 13. 论文里的可用表述

可以把这个模块描述为：

`Frequency-Separated Auxiliary Supervision`

或者更具体：

`Foreground-aware Low/High-Frequency Auxiliary Loss`

如果想强调它和现有高光模块的关系，可以写成：

`A lightweight frequency-separated auxiliary loss that preserves the original highlight-definition pipeline while decoupling smooth illumination consistency from sharp highlight residual supervision.`

## 14. 一句话概括

这个模块的本质不是“重新定义高光”，而是：

**在不改变现有高光监督模块的前提下，用 Gaussian low-pass + residual high-pass 的方式，把整体照明约束和高光细节约束拆开，让模型同时兼顾 `ra/tu` 和 `uu/us`。**

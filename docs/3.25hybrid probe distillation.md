# 2026-03-25 Hybrid Probe Distillation

这次把 `hybrid probe distillation` 作为一个独立训练模式接进来了，不再把 `latent probe` 只做成纯 replacement。

目标是：

- 前半程保留 image-space highlight branch，当高信息量 teacher
- 同时训练 latent probe 去拟合同一套 highlight score
- 后半程逐步降低 image-space branch 的权重，同时提高 probe loss 权重
- 尽量保住主指标，同时减轻训练对 decode-backprop 的依赖

核心代码在 [neural_gaffer_training.py](/4T/CXY/Neural_Gaffer/neural_gaffer_training.py)：

## 当前行为

这套 schedule 的实际含义是：

- `0 - 20k`：保持原 image-space teacher 强监督，同时训练 probe
- `20k - 32k`：线性把 image-space 约束缩到原来的 `25%`
- `20k - 32k`：同时把 probe loss 放大到原来的 `2x`
- `32k+`：稳定在一个混合状态，而不是立刻纯 replacement

所以它不是“前半程 image，后半程纯 probe”，而是一个更保守的知识迁移版本。

## 方法意义

相对纯 replacement，这个版本的论文价值更强：

- 保留 image-space branch 的高信息量 RGB teacher
- 让 probe 在同一训练里接受蒸馏，而不是独自硬扛全部辅助监督
- 后期逐步把 highlight guidance 从 image-space 转到 latent-space
- 更适合作为“效果版主方法 + 效率版蒸馏变体”之间的桥梁

## 下一步看什么

最关键的观察点有 3 个：

- 主 held-out split 是否能明显好于纯 replacement
- `random_area_light_condition` 是否还能保住或小幅提升
- 训练后半程的速度/显存是否比纯 image-space 更友好

如果这版能把主指标拉回去，同时保住部分效率收益，它就很适合作为论文里的第二方法点。


**判断**
从发论文的角度，下一步最重要的不是继续“多加一个小技巧”，而是先把方法主线收拢。

你现在其实已经有两条很不一样的故事：

- 主效果线：`foreground-aware + quantile + blur-for-threshold + local-relative highlight + image-space highlight guidance`
- 效率线：`latent-space probe / decode-free replacement`

这两条里，前者已经证明“主指标整体变强”，后者目前只证明了“更省、更快、对某个 split 更友好”，但还没有证明“整体更好”。所以如果是冲论文，我建议：

**主方法先定为前者，不要把 probe 当主贡献**
原因很直接：

- 目前最强结果还是来自你那条 image-space 分支保留的版本，尤其是 [3.22gass_blur_change.md](/4T/CXY/Neural_Gaffer/docs/3.22gass_blur_change.md) 里这条主线。
- `probe replacement` 现在更像一个有潜力的效率变体，而不是主方法，因为它伤了 `unseen_object_with_unseen_envir` 和 `unseen_object_with_seen_envir` 这两个更核心的 held-out 指标，见 [3.23 latent-space highlight probe.md](/4T/CXY/Neural_Gaffer/docs/3.23%20latent-space%20highlight%20probe.md)。

**下一步最值得做的实验**
如果只做一个最关键的新实验，我建议做：

- `hybrid probe distillation`，不是继续纯 replacement

具体思路是：

- 前半程保留 image-space highlight branch，当老师
- 同时训练 latent probe 去拟合 highlight score
- 后半程逐步降低 image-space weight，把一部分监督转给 probe
- 最终目标不是完全替代，而是“尽量接近主模型效果，同时减少 decode-backprop 依赖”

这条比继续硬做纯 probe replacement 更有论文价值，因为它更容易同时拿到两点：

- 主性能不明显掉
- 训练代价下降

这样你的 paper 就能形成一个更完整的结构：

- 一个效果更强的高光建模方法
- 一个更高效的 latent-space 近似训练策略

**为什么这是现在最好的方向**
因为你当前最强的创新已经够讲一个方法了：

- 前景感知高光建模
- 自适应分位数阈值
- 局部相对亮度定义
- 仅用于阈值估计的 blur，保留原始亮度算最终 score

这条线物理直觉强、改动集中、消融也好做。  
相反，probe 现在单独拿出来当主方法，审稿人很可能会问一句：既然主指标掉了，为什么要用它？

所以更好的姿势是：

- 主方法：`foreground-aware relative quantile highlight guidance`
- 附加方法点：`decode-free latent highlight distillation`

**建议你接下来按这个顺序推进**
1. 锁定当前最强 image-space 版本，作为论文主 baseline。  
2. 做一组 hybrid probe 实验，而不是纯 replacement。  
3. 补完整 ablation：`fg mask -> quantile -> blur -> relative -> image-space -> hybrid probe`。  
4. 单独做一张效率表：训练速度、峰值显存、主指标。  

**不建议现在优先做的事**
- 不建议继续堆新的 highlight 定义小技巧。
- 不建议把纯 probe replacement 直接写成主方法。
- 不建议再开太多并行方向，不然论文故事会散。

**一句话结论**
从论文角度，下一步最该做的是：  
把“前景感知相对分位数高光引导”定成主方法，再把 probe 做成一个“效率增强版/蒸馏版”去救回来，而不是让 probe 取代主线。
